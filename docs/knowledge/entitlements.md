# Entitlements

Synthetic allowance rules. Balances are on the balance resource. The product inventory shows whether the allowance exists.

## Allowances reset on the bill cycle

Voice, data and SMS allowances reset when the bill cycle starts, if the entitlement is marked to reset. A balance that still shows the previous cycle's consumption after the reset time is an allowance that did not reset. Compare the balance period with the bill period before you say the allowance is wrong.

## Packs that were never activated

An add-on or pack that was sold but never activated has no usable balance. The customer can be charged for use that the pack would have covered. Say that the pack is not active. Do not invent a remaining balance.

## Overlapping packs

Two packs that cover the same usage in the same window must be applied once. Counting both is a double grant. Dropping both is a missing grant. Read the product list and the balances together.

## Covered usage

Usage inside an active allowance or pack should not appear as overage. An overage line on covered usage is a fault. Credit requires a CSR proposal after the balance shows the usage was inside the grant.

## Promotional data

A promotional data bonus lasts for the number of months on the offer. Ending it early removes the grant while the offer should still be valid. Check the offer dates on the product before explaining a sudden overage.
